# docs/

Single-page site for GitHub Pages: the Pico CSS (classless) page in
`index.html` plus the screenshots and demo it embeds in `assets/`.

GitHub Pages should be configured to serve from the `main` branch, `/docs`
folder.

Test locally with:

```sh
python3 -m http.server -d docs 8000
```

then open <http://localhost:8000>.
